Cookie Policy

Last updated: September 23, 2026
Nothing to disclose today, written for when that changes. Confirmed against this site's actual code: thenoctemcollective.com sets no cookies and loads no analytics or tracking scripts today, and the Noctem Social mobile app doesn't use browser cookies at all — it's a native app, not a web page. This policy describes the categories we'd use if that ever changes, so nothing gets added without this page being accurate first.

1. What cookies are

Cookies are small text files a website can store in your browser to remember information between visits. "Cookies" here also covers similar browser-storage technologies like local storage.

2. What we use today

Nothing. thenoctemcollective.com is currently a static site with no login, no forms that persist data client-side, and no analytics — there is no cookie of any kind set anywhere on this domain right now.

3. Categories we'd use if that changes

If we ever add functionality that requires cookies, we'll classify each one into a category below, and only strictly-necessary cookies will be set without asking first:

CategoryWhat it's forRequires consent?
Strictly necessary Required for the site to function at all — e.g., keeping you signed in on a page that needs it No — but we'll still disclose it here
Functional / preference Remembers a choice you made, like a light/dark mode preference Yes
Analytics Helps us understand how visitors use the site, in aggregate Yes
Marketing Not currently planned — we don't run ads Yes, if ever introduced

4. Before any non-essential cookie is ever set

We'll add a real cookie-consent banner to this site — opt-in, not pre-checked, matching the "explicit consent" standard we already hold ourselves to in the Noctem Social app itself. This isn't built yet because there's nothing for it to gate.

5. Third-party cookies

We don't currently embed any third-party service on this site that would set its own cookies (no embedded video, no social widgets, no ad network). If that changes, we'll name the specific service here.

6. Controlling cookies in your browser

Most browsers let you block or delete cookies through their settings. Since this site sets none today, there's nothing to block right now — this section exists for when that's no longer true.

7. Changes to this policy

If we ever add a cookie of any kind to this site, we'll update this page (and add the consent banner described above) before that cookie is ever set, not after.
